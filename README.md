# HackerDNA Write-ups

Repositório contendo write-ups e documentação dos laboratórios concluídos na plataforma HackerDNA.

Os relatórios têm como objetivo registrar metodologias de enumeração, exploração e pós-exploração utilizadas em ambientes controlados de treinamento, contribuindo para o desenvolvimento contínuo de conhecimentos em Segurança da Informação e Cybersecurity.

## Laboratórios Documentados

| Laboratório   | Categoria                  | Dificuldade |
| ------------- | -------------------------- | ----------- |
| Cronpocalypse | Linux Privilege Escalation | Fácil       |
| SQL Injection | Web Application Security   | Fácil       |

## Competências Desenvolvidas

* Reconhecimento e Enumeração
* Web Application Security
* SQL Injection
* Linux Privilege Escalation
* Credential Discovery
* Exploração de Vulnerabilidades
* Análise de Impacto
* Documentação Técnica

> Todos os laboratórios foram executados em ambientes autorizados de treinamento da plataforma HackerDNA.
